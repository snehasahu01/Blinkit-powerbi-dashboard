Project Title / Headline

🛒 Blinkit Sales Analytics: Interactive Outlet & Product Performance Dashboard

A dynamic and interactive Power BI dashboard built to explore Blinkit sales performance, focusing on outlet types, product categories, outlet locations, outlet sizes, fat content, sales trends, and customer ratings.

2. Short Description / Purpose

The Blinkit Sales Analytics Dashboard is a visually engaging Power BI report designed to analyze and compare sales performance across different outlet types, locations, sizes, and product categories.

The dashboard provides key insights into total sales, average sales, number of items, average rating, outlet establishment trends, item types, fat content, and outlet performance, helping businesses make data-driven decisions related to sales, inventory, and outlet optimization.

3. Tech Stack

The dashboard was built using the following tools and technologies:

📊 Power BI Desktop – Main data visualization platform used for creating the interactive dashboard.
📂 Power Query – Used for data cleaning, transformation, and preparation.
🧠 DAX (Data Analysis Expressions) – Used for calculated measures, KPIs, and analytical calculations.
📝 Data Modeling – Used to organize the dataset and enable interactive filtering and analysis.
📈 Data Visualization – Used charts, KPI cards, donut charts, bar charts, line charts, and tables to present insights.
📁 File Format – .pbix for the Power BI report and .png for dashboard preview.

5. Features / Highlights
🔹 Business Problem

Retail businesses generate large amounts of sales data across multiple products, outlet types, sizes, and locations. Analyzing this data manually can make it difficult to quickly identify the factors driving sales performance.

Important questions include:

Which product categories generate the highest sales?
Which outlet types perform best?
Which outlet locations contribute the most sales?
Does outlet size affect sales performance?
Which fat-content category generates higher sales?
How have sales changed according to outlet establishment year?

The dashboard addresses these questions by transforming raw sales data into an interactive and easy-to-understand business intelligence report.

🎯 Goal of the Dashboard

The main goal of the dashboard is to provide an interactive analytical tool that:

Monitors overall sales performance.
Identifies high-performing product categories.
Compares different outlet types.
Analyzes sales by outlet size and location.
Tracks outlet establishment trends.
Provides insights into product fat content.
Supports data-driven business and sales decisions.
